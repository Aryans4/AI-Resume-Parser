# AI Resume Parser 🤖

An AI-powered resume parsing project that uses the Groq API and structured outputs to extract useful information from resumes and analyze job descriptions.

## ✨ Features

- Resume parsing from PDF and DOCX files
- AI-powered job description analysis
- Structured output using Pydantic
- Extraction of required and preferred skills
- Education and experience requirement extraction
- Job responsibilities extraction
- Groq API integration
- Environment variable based API configuration

## 🛠️ Tech Stack

- Python
- Groq API
- Pydantic
- PyPDF
- python-docx
- python-dotenv
